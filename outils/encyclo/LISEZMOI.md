# Encyclopédie du wiki

Chaîne : `outils/wiki_complet.py` (relevé fandom vers `_fandom/`) → `extraire.py` (HTML en blocs) → `images.py` + `animwebp.py` (images WebP, doublons retirés) → `build.py` (nettoyage, gabarits répétés, One Piece retiré) → `export.py` (fiches, FR via `dico_fr.json`) → `site/wiki/encyclo.json` + `site/wiki/encyclo/`.
